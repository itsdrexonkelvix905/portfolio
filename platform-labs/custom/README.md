## How to add a new challenge

1. Create a folder at platform-labs/custom/labs/<challenge-slug>/.
2. Inside it, create:
   - index.html
   - README.md
   - writeup.md
   - methodology.md
   - findings.md
   - lessons-learned.md
   - references.md
   - assets/screenshots/
   - assets/diagrams/
   - reports/
   - files/
3. Edit index.html to describe the challenge.
4. Add the challenge to the PLATFORM_LABS array in the root index.html.
5. Save and refresh. It appears under both Platform Labs and All Labs.
